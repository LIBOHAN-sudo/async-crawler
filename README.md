# Python异步爬虫 | 网页爬虫 | Redis去重

一个生产级的**异步爬虫**框架，使用**Python** + **aiohttp** + **Redis**实现，支持高并发、自动重试、代理轮换等功能。

## 功能特点

- **异步IO**：基于asyncio和aiohttp，高效并发
- **Redis持久化**：URL队列、去重、统计信息存储
- **自动重试**：支持指数退避重试策略
- **User-Agent轮换**：模拟不同浏览器
- **代理支持**：自动检测并移除失效代理
- **实时统计**：爬取进度实时监控
- **完整日志**：分级日志记录，支持文件轮转
